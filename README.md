# ЭкоОтчёт

Программа для экологов предприятий Казахстана: берёт файлы расчёта выбросов и
PDF-протоколы лаборатории и сама заполняет шаблоны портала НБД
(iec.ndbecology.gov.kz) и статформы — ПЭК, СЗЗ, Источники, Отходы, Вода, Почва,
Регистр платы (Форма 870.00), 2-ТП (воздух), 2-ТП (водхоз), 2-Отходы, РВПЗ.

В этом репозитории — **только готовые сборки** программы (раздел
[Releases](../../releases)). Исходного кода здесь нет.

## Установка

1. Откройте [последний релиз](../../releases/latest) и скачайте архив
   `EcoOtchet_<версия>.zip`.
2. Распакуйте в любую папку **вне** «Program Files», например на Рабочий стол.
3. Запустите `EcoOtchet.exe`. Устанавливать Python и другие программы не нужно
   (Windows 10/11, 64 бит).

## Обновления

Программа сама проверяет обновления при запуске (и по кнопке «⟳ Обновления»),
скачивает только изменившиеся файлы и перезапускается. Ваши настройки,
предприятия и записи не затрагиваются. Описание каждой версии подписано
цифровой подписью — программа ставит только подлинные обновления.

Остальные файлы релиза (с длинными именами) — части обновлений, вручную их
скачивать не нужно.

и их лицензии — в файле `THIRD_PARTY_LICENSES.txt` внутри архива.
